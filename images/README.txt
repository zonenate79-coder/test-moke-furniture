# MOKE FURNITURE - LOCAL IMAGE DIRECTORY
# ========================================

Store your brand's high-resolution photography and 3D assets in this folder.

Examples:
- images/sofas/nordic-boucle.jpg
- images/chairs/brutalist-lounge.jpg
- images/tables/sculptural-dining.jpg

When referencing local photos in builder.html or data/products.js, use:
images/your-image-name.jpg

These files will be served directly by your web host once deployed.
